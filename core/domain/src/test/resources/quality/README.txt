Short excerpts of the FLAC decoder testbench by Martijn van Beurden
(https://github.com/ietf-wg-cellar/flac-test-files), which is in the public
domain (CC0), encoded again with FFmpeg's FLAC encoder:

music-16bit-stereo.flac  44.1 kHz, 16 bit, stereo, linear prediction
music-16bit-fixed.flac   44.1 kHz, 16 bit, stereo, fixed predictors, blocks of 1152
music-24bit-mono.flac    96 kHz, 24 bit, mono
